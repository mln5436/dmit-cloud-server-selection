# 免备案云服务器：不用等 ICP 审核，香港、东京、洛杉矶节点怎么选才不踩晚高峰的坑

搜「免备案云服务器」的人，卡点基本都一样：知道要买境外机器，但不知道买哪儿的。香港怕贵，美国怕慢，日本怕晚高峰绕路。这篇文章把这道选择题拆开，顺便把 DMIT 这家常被当成「顶配答案」的商家摊开讲——它的钱花在哪，哪些套餐其实没必要上。

## 一、「免备案」免的到底是什么

免备案不是一个产品属性，是服务器位置带来的结果。

工信部的规则很干脆：服务器放在中国大陆境内，域名解析到这个 IP 对外提供网站服务，就得走 ICP 备案。机器放在香港、澳门、台湾，或者美国、日本、新加坡，不归这套流程管，买完配好环境就能开站。备案周期动辄十几个工作日，加上材料反复补，这是很多人绕开它的唯一原因。

有两件事得先说清楚，免得后面踩坑：

- 只跑 SSH、API、数据库、定时任务这类不绑域名的用途，用哪儿的机器都不涉及备案，这条常常被忽略；
- 免备案不等于免监管。内容合不合规，归机房所在地的法律管，拿它做钓鱼、侵权、诈骗，照样停机。

这张表里最容易看漏的一点是：同样标着「香港 VPS」，走普通国际线和走 CN2 GIA，白天的 ping 可能只差十几毫秒，到了晚上 20:00–23:00 能差出四五倍。第三方对比里常见的「香港节点平均 18ms、丢包 0.3%」这类数据，前提是测试机走了优质线路；换成普通线，晚高峰丢包冲到 3%–5% 也不稀奇。

所以买之前做一件事就够了：跟商家要测试 IP，自己 ping 一遍，再用 mtr 看回程经过哪些节点。白天快、晚上炸的机器，不适合当主力站。

## 三、比配置表更值得看的四个指标

**线路类型。** 电信 CN2 GIA、联通 AS9929、移动 CMIN2 属于运营商高端国际专线，价格贵但晚高峰稳定；163 骨干、普通 BGP 便宜，堵起来很难受。商家标「BGP」不说明任何优化，标「三网直连」才需要追问具体走哪几条。

**流量超了之后会发生什么。** 这一条被绝大多数选购指南漏掉，但实际影响很大。有的商家直接停机，有的按 GB 收超额费，账单能吓人一跳。DMIT 的做法是超量后降到 4–10Mbps 继续跑，不额外收费，对流量波动大的站点友好得多。

**IP 是不是原生、能不能换。** IP 注册地和机房所在地一致，才算原生 IP，做跨境电商和账号运营时这点直接决定能不能用。另外要问清楚换 IP 的政策和费用。

**虚拟化方式和系统权限。** KVM 才能拿到独立内核，自己装 Docker、改内核参数、跑自定义系统都没问题；OpenVZ 之类的共享内核方案，越到后面越受限。

它的定位从来不是最便宜。DMIT 的产品线按网络质量分成几档，这个分类是理解它价格逻辑的关键：

- **Premium（Pro）**：电信去程 CN2 GIA，三网回程走 CN2 GIA（IPv6 方向走 9929 / CMIN2）。三档里最贵，也最适合面向大陆用户的场景。

硬件上用的是 AMD EPYC 系列处理器加 NVMe SSD，默认给 1 个 IPv4 和 1 个 IPv6 /64。官方宣称的网络在线率是 99.9%。付款方式上，多篇第三方整理都提到支持支付宝、PayPal 和信用卡，对国内用户来说省了一次换汇。

## 八、下单前确认这几件事

DMIT 香港和洛杉矶的 Pro、EB 系列，符合条件时可以免费更换 IPv4，条件大致是：实例已开通满 7 天、距上次换 IP 至少 15 天、ICMP 和 TCP 全端口都不可达、剩余服务期不少于 7 天。对经常担心 IP 被墙的用户来说，这条比多给 1GB 内存有价值。

另外几点值得提前知道：

- 流量是双向计费，上传和下载都算，别按「月流量 = 下载量」去估算；
- 内存和硬盘可以加购定制，但价格是叠加的，升级前先算清楚长期成本；
- 拿到 IP 之后先跑一遍三网 mtr，确认回程没有绕路，有异常尽早提工单；
- 年付折扣力度大于月付，但新用户第一台机器建议先月付跑一个月，确认线路稳定再续长期。

## 九、几个高频问题

**免备案云服务器会不会影响 SEO？** 搜索引擎没有公开规则说境外机器不收录，实际影响来自抓取稳定性和响应速度。百度蜘蛛在国内，抓境外机器本身没问题，但如果回程线路绕了美国，抓取频次会掉。用香港优化线路加国内 CDN 回源，是常见做法。

**免备案的机器能绑几个域名？** 绑域名的数量取决于套餐和面板限制，跟备案没关系。备案管的是「能不能绑」，不是「能绑几个」。

**流量用完了会直接停机吗？** 看商家。DMIT 是限速继续跑，4Mbps 到 10Mbps 不等，站点不会突然挂掉；也有商家直接停服务或者按 GB 计费。这一条在选购时一定要问清楚，属于典型的「买之前不问，出事才后悔」。

**香港和日本到底怎么选？** 目标用户在大陆，香港的物理距离优势没法替代；用户分布在中日韩或者需要日区 IP，选东京。价差接近一半，别为了「香港听起来更快」多花这笔钱。
